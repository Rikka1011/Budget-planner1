BIWEEKLY BUDGET PLANNER - installable app (PWA)

Files: index.html, manifest.webmanifest, sw.js, icon-*.png
All files must stay together in the same folder.

Put this folder on any HTTPS web host (Netlify Drop, GitHub Pages, Cloudflare Pages).
Opening index.html straight from a phone's file manager will NOT install as an app,
because installing requires https.

To install:
- iPhone: open the link in Safari > Share > Add to Home Screen
- Android: open the link in Chrome > menu > Install app
